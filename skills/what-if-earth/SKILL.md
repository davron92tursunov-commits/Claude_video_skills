## 1. Hook first
Write 4-5 hook options (spoken line + on-screen text + first visual, one-line reason each, mark your pick). Score against:
1. **Stakes for the viewer** ("you", "your", "around you") or for Earth. 2. **Surprise / contradiction**. 3. **One concrete number or image**
in the first line. 4. **Open loop**. 5. **Visual moves in frame 1** (no title card). Keep ≤ 8 words before "Right now?".
Pattern that works: `<startling present-tense claim>. / Right now? / Not yet. / So, what if ...?` The claim is shown first, then "Right now?" (red,
blinking dot), then "Not yet." undoes it. Rotate hook types: shocking fact, direct question, countdown, myth, comparison.

## 2. Script (~20 lines, 160-175 words)
- Hook (3 lines) → "So, what if <topic>?" → a number right away → very short sentences, many 2-4 word lines, numbers spelled out for TTS.
- Escalation: 3-5 stages each with its own number; one myth-bust in second person ("But you wouldn't suffocate.").
- "Then comes the scary part." → "Don't worry." + a timescale or a real recent fact (e.g. satellites show more green leaves) → closer, always:
  "Follow to see how Earth really works."
- **Fact-check every number**; mark estimates "ESTIMATE" on screen and in the description; tell the user which numbers changed and why.
- Files in the project root: `<Topic>.txt` (TITLE with emoji, DESCRIPTION with plain-word facts + "X is an estimate." + "Visuals are simplified and illustrative."
  + CREDIT lines + "Follow for more Earth mechanics." + 4 hashtags ending #Shorts, PINNED COMMENT "Would you rather ...? 👇" + caveat in parentheses,
  VOICEOVER numbered list with VISUAL notes, FACT CHECK) and `TTS_Prompt_AI_Studio.txt`.
- TTS prompt format (the parser requires these exact headings): `VOICE: Fola` / `=== STYLE INSTRUCTIONS ===` (documentary narrator, warm, curious,
  135-140 wpm, pause after each sentence, longer pause before "Right now?", "So, what if" and "Don't worry."; "Right now?" low and serious; question rising;
  stress numbers; "Then comes the scary part." slower and darker; calm from "Don't worry.") / `=== TEXT ===` (one sentence per paragraph).

## 4. Engine: one WebGL canvas (template `templates/earth_short/hf`)
Copy the template to `Earth_mechanics_N/project/hf` (do not copy `audio/mix.wav` or renders). Files:
- `js/core.js` Three.js renderer + bloom + grade (grain, vignette, chromatic aberration). `js/globe.js` realistic Earth (NASA textures, terminator, city lights,
  bump, ocean glint, clouds, atmosphere) with **uniform effects**: `uGreen` (Sahara green front), `uLake`, `uDry` (Amazon pale), `uHL`/`uUS` (outlines from
  `tex/masks.png`: R Sahara, G Amazon, B USA), `uIce` (polar ice latitude), `uBandLat/uBandA` (rain belt glow), `uWetB/uDryB` (wet/dry belts),
  `uTree` (forest -> bare soil, negative = greener). Make new masks with `tools/make_masks.py` (Natural Earth regions).
- `js/scenes.js` scenes, each `{scene, exposure, update(lt, P)}`: `earthScene` (globe + axis + Moon + Mars + CO2 dust cloud; `P.tilt` rotates the axis about Z with the Sun fixed on
  the left = physically correct seasons), `parkScene` (grass, Kenney trees that vanish/bloom/gold, hill+river slide, heat, the hero). The desert scene of _21 (ridged-noise dunes,
  rain, grass/palm growth, lake, hippos, hero on a crest) is in `examples/Earth_mechanics_21/scenes.js`.
- `js/main.js` the SHOTS table `[start, end, scene, paramFn(t,k), hudFn(t)]` with comments giving the spoken word time; HUD: small label + big number (counting up with
  `cnt`) + sub + source line; red "RIGHT NOW?"; gauge; end card (FOLLOW pill tapped by the cursor; the last 0.6 s fades to black to loop).
- `js/person.js` + `models/hero.glb`: faceless yellow-hoodie hero (never add eyes/mouth; emotion through pose: point, wave, lookUp, lean). `ry = PI` = back to camera.
- `index.html` HUD elements; set `data-duration` and the `<title>`.
Globe facts: view longitude with `rotation.set(lat, -PI/2 - lon, 0, 'XYZ')`. Sun from the left (`az -1.0`); `az 2.7` puts India on the night side (city lights).

## 5. QC loop (mandatory)
```bash
export PATH="<ffmpeg bin>:$PATH"; cd project/hf
npx hyperframes@0.8.162 snapshot --at 0.4,3,9,15,22,30,38,46,55,62 --no-end --timeout 120000 -o ../qc1 --describe false
```
Read `qc1/contact-sheet*.jpg`. Fix, re-snapshot only the changed times. A snapshot at an exact scene start looks black (0.1 s cut dip): not a bug.
Hard-won fixes: dunes need amplitude + a low side sun; put the camera on a terrain crest or a hill blocks the view; textured materials need a **strong** color
multiplier to change hue (e.g. (5.5,1,2.2) for mud); tint leaf materials AND add emissive or pink looks grey; animals must face the camera (heads toward +z) and sit
apart, 15+ m away; dust particles need 13-17 px; bloom blows out pale deserts (darken the sand).

## 6. SFX and mix
`make_sfx.py` (exec `sfx_lib.py`, set `DUR`): `put(sound, time, gain)` with boom, hit, pop, tick (counters via `cross_times`), ding, descend, pad, hum, heartbeat,
sparkle, click, rumble, drone. Hit points on scene starts and spoken numbers. **Never** use `whoosh()`, `riser()` or swept-noise "shhh" beds. Rain = many short pops.
```bash
ffmpeg -y -i Voiceover.wav -i sfx.wav -filter_complex "[0:a]aresample=44100,pan=stereo|c0=c0|c1=c0,apad=whole_dur=T,asplit[v][sc];[1:a]aresample=44100[s];[s][sc]sidechaincompress=threshold=0.04:ratio=5:attack=15:release=300[d];[v][d]amix=inputs=2:normalize=0:weights='1 0.55',loudnorm=I=-14:TP=-1.5:LRA=11,atrim=0:T" hf/audio/mix.wav
```

## 7. Render and upload copy
Render takes ~14 s per 1 s of video (Intel UHD). Start it detached so the shell does not hang, then wait with a background loop that also makes the upload copy:
```bash
nohup npx hyperframes@0.8.162 render -o ../../What_if_<Topic>_master.mp4 --quiet > ../render_master.log 2>&1 < /dev/null & disown
# background waiter: poll file size until stable (45 s), then 2-pass x264 -b:v 2900k + AAC 192k -movflags +faststart -> What_if_<Topic>_upload.mp4 (~25 MB)
```
The "task completed" notification of a launcher is NOT the render finishing: check the mp4 exists (ffprobe duration) before saying it is done. After it finishes extract 6 frames
from the master (`ffmpeg -ss t -frames:v 1`), look at them, then report master + upload paths, unverified parts and which numbers are estimates.
